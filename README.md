# 《口罩下的两年》

> 都市现实 / 治愈向 / 轻喜剧

## 项目简介

这是一部约15万字的都市现实主义小说，讲述了一个38岁的明星健身教练 Nick 在疫情期间的挣扎与重生故事。

### 故事核心

- **类型**：都市现实/治愈向/轻喜剧
- **主题**：面子与生存、中年困境、自我接纳
- **情感曲线**：压抑→挣扎→崩溃→释放→重生
- **风格**：笑中带泪，用幽默消解沉重
